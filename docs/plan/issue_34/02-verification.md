# Phase 02: Build and visual verification

## Goal

Verify that issue #34 guidance is built, localized, visually recognizable, and responsive.

## Scope

- Run the default checked-in/UI-only build.
- Run the repository verifier suite.
- Add or update browser verifier coverage for the new chart-reading summary.
- Perform focused desktop and narrow-width smoke checks.
- Update this plan with validation results.

## Non-goals

- Do not add new chart behavior beyond verification fixes.
- Do not refresh catalog data from a local Terra Invicta installation.
- Do not use `npm run deploy`.

## Affected files

- `tools/verify_drive_comparison_browser.mjs`
- Generated by build: `docs/index.html`, `docs/assets/js/**`
- This phase document

## Implementation steps

1. Run `npm run build`.
2. Run `npm run verify`.
3. If verifier coverage is insufficient, add focused assertions for:
   - visible chart-reading summary,
   - English/Korean localization,
   - lower-left tradeoff wording,
   - current assumption wording,
   - narrow-width overflow.
4. Run focused Playwright checks if full verifier output does not provide enough visual evidence.
5. Record validation outcomes and residual risks.

## Acceptance criteria

- Build succeeds using checked-in data.
- Full verifier succeeds.
- Browser verifier covers the new guidance and localization.
- Focused visual smoke confirms the summary is visible and readable on desktop and narrow widths.
- Generated files changed only through build.

## Validation commands

- `npm run build`
- `npm run verify`

## Manual smoke tests

- Desktop: confirm the guidance sits near the chart, below any chart warnings and above the plot.
- Mobile/narrow: confirm all cue labels and text wrap inside the chart shell.
- Language: confirm English and Korean copies do not mix.

## Rollback risks

- Browser verifier can become brittle if it asserts complete sentences. Prefer key phrases and structural checks.
- Generated output churn can be large; inspect source changes for review and treat generated files as opaque.
