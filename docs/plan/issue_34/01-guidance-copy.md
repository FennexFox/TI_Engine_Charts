# Phase 01: Chart-reading guidance copy and placement

## Goal

Add concise, visible chart-reading guidance that explains the chart axes, lower-left interpretation, acceleration caveat, and selected ship/dry-mass assumptions.

## Scope

- Add a chart-adjacent reading summary to `tools/drive_comparison_template.html`.
- Render localized guidance from source client code.
- Style the summary so it is visually recognizable, compact, and responsive.
- Keep the existing compact `Chart Guide` focused on visual symbols and Pareto help.
- Regenerate generated output through `npm run build`.

## Non-goals

- Do not change drive calculations, filtering behavior, Pareto logic, or chart point placement.
- Do not replace issue #31, #32, #33, or #38.
- Do not add mission planning, travel-time calculation, or mission-feasibility presets.
- Do not directly edit generated `docs/index.html` or `docs/assets/js/**`.

## Affected files

- `tools/drive_comparison_template.html`
- `tools/drive_comparison_styles.css`
- `tools/drive_comparison_client/chart/interaction.js`
- `tools/drive_comparison_client/state/core.js` if shared formatting/localized helpers are needed
- `tools/verify_drive_comparison_browser.mjs`

- This phase document

## Implementation steps

1. Insert a chart-reading summary root in the chart shell near existing chart warnings.
2. Add a renderer that creates short localized cue items:
   - X axis / left means lower cumulative research cost.
   - Lower on mass charts means lighter total/fuel mass for current target dV and current ship/dry-mass assumptions.
   - Lower-left is usually the first area to inspect, but acceleration and mission role can override it.
   - Current assumptions include selected Ship Designer status or dry mass, target dV, and acceleration threshold where visible.
3. Keep wording consistent with "Acceleration" in English.
4. Add CSS for a compact cue strip with stable wrapping on desktop and narrow widths.
5. Update verifier assertions for English, Korean, lower-left wording, selected assumptions, and responsive fit.

## Acceptance criteria

- First-time users can identify what the X and Y axes mean from text near the chart.
- Guidance says lower-left generally means less research and lower required mass under current assumptions.
- Guidance warns that acceleration and mission role may override lower-left.
- English copy uses "Acceleration" consistently.
- Guidance references selected Ship Designer/dry-mass assumptions and target dV where relevant.
- English and Korean text are both rendered from source.
- No generated files are edited directly.

## Validation commands

- `npm run build`
- `npm run verify`

## Manual smoke tests

- Open the generated page at desktop width and confirm the chart-reading summary is visible without opening the compact guide.
- Switch English/Korean and confirm the summary changes language without mixed-language text.
- Change Ship Designer/dry mass, target dV, and metric; confirm the assumptions and Y-axis cue update.
- Check a narrow viewport around 390px wide and confirm the summary wraps without overlapping chart controls or the plot.

## Rollback risks

- If the strip is too prominent, it can compete with chart warnings and the plot. Keep visual weight lower than actionable warnings.
- If copy is too generic, it will not satisfy the "where should I look first" goal. Keep the lower-left cue explicit.
- If dynamic state is not re-rendered on language/metric changes, the guide can become stale.
