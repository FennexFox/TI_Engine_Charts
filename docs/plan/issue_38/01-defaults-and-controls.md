# Phase 01: Default scale and chart-adjacent controls

## Goal

Make the first-run chart default to log/log and make the active scale/filter/display state easier to notice from the chart area.

## Scope

- Update the first built-in chart preset to `logX: true`, `logY: true`.
- Align template fallback checkbox state with log/log defaults.
- Add chart-adjacent Log X and Log Y controls that sync with the existing left-panel controls.
- Add a compact active-state summary near the chart for scale, filters, search, and major display mode.
- Update source localization for new labels/help text.
- Regenerate generated output through `npm run build`.

## Non-goals

- Do not redesign all chart interactions.
- Do not move every filter out of the left panel.
- Do not implement mission-feasibility presets or mission planning.
- Do not change drive calculations or axis math.
- Do not directly edit generated `docs/index.html` or `docs/assets/js/**`.

## Implementation steps

1. Change the first built-in chart preset's `logX` to `true`; leave `logY` true.
2. Change the source template fallback `#logX` checkbox to checked.
3. Add chart-adjacent `Log X` and `Log Y` checkboxes near existing chart summary controls.
4. Wire chart-adjacent scale controls to the same state as the left-panel checkboxes and keep both directions synchronized.
5. Render an active chart summary from source state:
   - active scale,
   - engine count,
   - category/family selection counts,
   - search active/inactive,
   - power view and connection-line mode where relevant.
6. Add static and dynamic localization for new labels and summaries.
7. Add or update verifier coverage for default log/log, explicit preset preservation, chart-adjacent controls, localization, and responsive layout.

## Acceptance criteria

- The default axis-scale choice is reviewed and documented in this plan.
- First-run built-in/default chart view uses log/log consistently.
- Saved/imported user presets preserve explicit `logX`/`logY` choices.
- Built-in/default preset migration behavior is intentional and documented in this plan and, if useful, a short code comment.
- Chart-adjacent scale controls and active summary make active scales/filters easier to notice.
- The left panel does not gain additional weight or duplicate detailed filter controls.
- Typical desktop and narrow-width layouts remain usable without text overlap.
- English and Korean labels/help text are updated consistently.

## Validation commands

- `npm run build`
- `npm run verify`

## Manual smoke tests

- First run with localStorage cleared: confirm X and Y are both log and chart points render.
- Toggle Log X/Log Y near the chart and confirm left-panel checkboxes, axis titles, and summary update.
- Apply or import a preset with `logX: false` and `logY: true`; confirm those explicit choices are preserved.
- Narrow viewport around 390px wide: confirm chart-adjacent controls and summary wrap without overlapping the plot.
- Switch English/Korean and confirm no mixed-language chart controls or summaries.

## Rollback risks

- If startup preset logic changes later, the first built-in preset may stop being the default source of truth.
- Duplicated scale controls can become stale if sync coverage is incomplete.
- Summary text can become noisy if it repeats too much left-panel detail.
