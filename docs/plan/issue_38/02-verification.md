## Goal

Verify that issue #38 defaults and chart-adjacent controls work, remain localized, and preserve explicit preset scale choices.

## Implementation steps

1. Run `npm run build`.
2. Run `npm run verify`.
3. Confirm verifier assertions cover:
   - first-run log/log default after built-in preset application,
   - explicit preset `logX`/`logY` preservation,
   - chart-adjacent Log X/Log Y controls syncing with left-panel controls,
   - active summary localization and narrow-width wrapping.
4. Perform focused visual smoke checks if verifier evidence is not enough.
5. Record results, changed files, and remaining risk.

## Acceptance criteria

- Build succeeds using checked-in data.
- Full verifier succeeds.
- Browser verifier proves the default and preservation behavior relevant to issue #38.
- Desktop and narrow-width views show no chart-control overlap or unreadable summary text.
- Generated files changed only through build.
